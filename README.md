# 🍳 Что приготовить?

Планировщик меню на неделю для семьи из 5 человек в Алматы. Помогает маме Олесе выбрать блюда, составить меню и список покупок с ценами из **Magnum Cash & Carry**.

## Возможности

- **Бюджет** — выбор недельного бюджета или без ограничений
- **Категории** — быстрые блюда, низкие калории, семейные любимые, здоровая еда, «обожраться», казахская кухня, детские
- **Диета** — вегетарианская, без глютена, кето, низкоуглеводная
- **Меню на 7 дней** — с рецептами, ингредиентами и пошаговым приготовлением
- **Список покупок** — с актуальными ценами из каталога Magnum Алматы
- **Замена блюд** — если что-то не нравится, можно заменить
- **Редактирование списка** — отметить что уже есть дома, добавить/удалить продукты
- **AI (опционально)** — подключите OpenAI API ключ для умных рекомендаций

## Запуск локально

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## Деплой на Vercel

1. Загрузите репозиторий на GitHub
2. Импортируйте проект в [Vercel](https://vercel.com)
3. (Опционально) Добавьте `OPENAI_API_KEY` в Environment Variables

## Переменные окружения

| Переменная | Обязательная | Описание |
|-----------|-------------|----------|
| `OPENAI_API_KEY` | Нет | Ключ OpenAI для AI-рекомендаций |

## Технологии

- Next.js 16 + TypeScript
- Tailwind CSS
- Zustand (сохранение в localStorage)
- Magnum API (magnum.kz:1337)
- OpenAI (опционально)

## Magnum API

Приложение получает актуальные цены продуктов через внутренний API Magnum Cash & Carry (`https://magnum.kz:1337/api/products`). При недоступности API используются примерные цены.
